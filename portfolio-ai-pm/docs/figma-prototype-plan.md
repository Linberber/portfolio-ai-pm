## 1. 概述与目标

### 1.1 原型目标

本原型用于 AI 产品经理求职作品集，展示科研选题副驾系统的核心交互逻辑。重点呈现：
- **HITL（Human-in-the-Loop）设计**——2 个人工确认节点
- **7 个设计特征（D1-D7）**的 UI 落地
- **完整工作流**：从模糊想法到选题报告

### 1.2 页面范围

共 5 个关键页面，覆盖 8 步 Workflow 中最核心的交互：

```
① 输入页 → ② 选题方向页 → ③ 文献列表页 → ④ 评分对比页 → ⑤ 报告预览页
         （确认点 1）      （确认点 2）
```

### 1.3 原型规格

| 属性 | 选择 |
|------|------|
| 保真度 | **高保真**（真实配色、文案、数据） |
| 交互 | **可点击跳转**（Prototype + Smart Animate） |
| Frame 尺寸 | **1440 × 900**（桌面端，学术工具感） |
| 字体 | PingFang SC / Microsoft YaHei |

## 3. 页面 ① 输入页

### 标题栏
- 左侧：🧪 图标 + "科研选题副驾"（18px SemiBold）
- 下方：进度条 — Step 1/5 高亮，"告诉我们你的研究方向"

### 主体内容区（居中，宽 640px）

**表单字段**：

1. **研究领域**（必填）
   - 标签："研究领域 *"
   - 输入框 placeholder："例如：神经调控、合成生物学、机器学习"
   - 单行，44px 高

2. **初步想法**（选填）
   - 标签："初步想法（选填）"
   - 多行文本框，120px 高
   - placeholder：两行示例文字
     > "例如：想开发基于柔性电子的闭环神经调控系统，
     > 用于改善抑郁症治疗效果"

3. **偏好设置**（两列并排）
   - 左："年份偏好" + 下拉选择（默认"近 5 年"）
   - 右："研究类型偏好" + 下拉选择（默认"不限"）

**引导卡片**（`#EFF6FF` 背景，左侧蓝色竖线）：
- 💡 标题："不知道怎么填？"
- 内容：试试用自然语言描述——
  > "我是生物研一学生，导师做神经调控方向，我想找一个 2 年内能做完的选题"

**底部操作**：
- 右对齐："开始选题分析 →" 主按钮
- 点击后：按钮变为 loading 态（旋转图标 + "分析中..."），1.5s 后跳转页面②

## 4. 页面 ② 选题方向页

### 标题栏
- 进度条：Step 2/5 高亮，"确认选题方向"

### 说明文字
"根据你的输入，我们拆解了 3 个候选研究方向："

### 方向卡片 ×3（每个 20px 内边距）

每张卡片结构（从上到下）：
```
┌──────────────────────────────────────────┐
│ ⚡ 方向 A              [ ✏️ 编辑 ] [ ✕ ] │  标题行
│ 基于柔性电子材料的闭环神经接口设计         │
│ ─────────────────────────────────────── │  分割线
│ 聚焦可拉伸电极材料的制备与神经信号         │  描述
│ 采集性能优化                             │
│                                         │
│ 创新性 ⭐⭐⭐⭐   可行性 ⭐⭐⭐           │  预评行
│                                         │
└──────────────────────────────────────────┘
```

三张卡片的具体内容：
- 卡片 A：⚡ 方向 A（硬件方向），创新性 4⭐ / 可行性 3⭐
- 卡片 B：🔬 方向 B（算法方向），创新性 5⭐ / 可行性 3⭐
- 卡片 C：🧬 方向 C（材料方向），创新性 3⭐ / 可行性 4⭐

### 添加入口
- `+ 添加自定义方向`（虚线边框卡片，点击展开输入框）

### 人工确认点 ① 面板

- 蓝色顶部边框（3px `#2563EB`）+ `#EFF6FF` 背景
- 👤 "人工确认点 ①" 标题
- "✅ 我已确认以上选题方向，开始文献检索 →" 主按钮
- "💡 提示：你可以修改、删除或新增方向" 辅助文字

**交互**：
- ✏️ → 标题和描述变为可编辑文本框
- ✕ → 弹出确认 toast "确定删除方向 A？"（剩余方向 ≥2 个才能删）
- 确认按钮 → 跳转页面③

## 8. Figma 搭建指引

### 8.1 准备工作

1. 新建 Figma 文件：`科研选题副驾-原型`
2. 创建 Page 1：`🧩 Design System`
3. 创建 Page 2：`📱 Prototype`

### 8.2 搭建顺序

**阶段 1：设计系统（约 30 分钟）**

在 `🧩 Design System` 页：

1. 创建 Color Styles（选中矩形 → 右侧 Fill → `⋮` → Create Style）
   - `Primary/Blue` = `#2563EB`
   - `Success/Green` = `#16A34A`
   - `Warning/Yellow` = `#F59E0B`
   - `Danger/Red` = `#DC2626`
   - `Neutral/Background` = `#F8FAFC`
   - `Neutral/Card` = `#FFFFFF`
   - `Neutral/Border` = `#E2E8F0`
   - 等等

2. 创建 Text Styles
   - `H1` / `H2` / `H3` / `Body` / `Caption`

3. 创建组件（Components）：
   - Button/Primary, Button/Secondary, Button/Danger
   - Input/Text, Input/Textarea, Input/Select
   - Card/Default
   - Tag/L1, Tag/L2, Tag/L3
   - Stepper/Active, Stepper/Done, Stepper/Inactive
   - 均使用 Auto Layout（Shift+A）

**阶段 2：搭建 5 个页面（约 2-3 小时）**

在 `📱 Prototype` 页：

1. 创建 5 个 Frame（1440×900），命名：
   - `01-输入页`
   - `02-选题方向页`
   - `03-文献列表页`
   - `04-评分对比页`
   - `05-报告预览页`

2. 每个页面从上到下搭建：
   - 顶部栏（使用 Stepper 组件实例）
   - 内容区（居中 940px 宽）
   - 操作区（底部固定或跟随内容）

3. 注意：
   - 5 个页面的顶部栏用同一个组件实例保持一致性
   - 卡片内部用 Auto Layout 方便后续修改
   - 给每个可点击元素起清晰的名字（如 `Btn_Confirm_Direction`）

**阶段 3：填充内容（约 1 小时）**

- 使用本文档中给出的具体文案
- 文献数据参考 PRD 中的格式（DOI、期刊名）
- 评分数据使用文档中的数值

**阶段 4：加交互连线（约 15-30 分钟）**

切换到 Prototype 模式：

| # | 触发元素 | 动作 | 目标 Frame | 动画 |

**阶段 5：检查（约 15 分钟）**
