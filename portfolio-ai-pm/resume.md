## 项目经历

### Q 版农村 — AI 辅助开发的桌面种植游戏

> 独立开发者 / 产品负责人 | 2026.05

**内容**：一款 2.5D 斜视角桌面农场游戏，透明无边框窗口浮于桌面，木框种植台风格。支持 4 种作物（草莓 / 向日葵 / 胡萝卜 / 豌豆）、5 个生长阶段、5 种操作（浇水 / 施肥 / 种植 / 收获 / 移除）。全程使用 Claude Code + DeepSeek 进行 AI 辅助开发，独立完成从需求分析、功能拆解、交互设计到代码实现的完整流程。

**业绩**：零外部依赖（仅 Python tkinter），实现了透明窗口、2.5D 渲染、悬浮气泡 Tooltip、存档读档、窗口拖动等完整功能。验证了 AI Coding 独立交付产品的能力。

### Agent 产品方案设计 — 科研选题辅助系统

> 产品方案设计 | 2026.03

**内容**：面向生物专业研究生"选题难、文献检索慢"的痛点，设计了一款基于 AI Agent 的科研选题辅助系统。完成用户画像分析、8 步核心 Workflow 设计（含 2 个人工确认节点）、系统边界定义（6 项能力范围与 5 项限制）、3 级文献来源分级规则、观点冲突检测策略及效果评估方案。

**业绩**：输出完整产品方案文档，含 PRD（15 章）、竞品分析报告（D1-D7 框架）、Figma 高保真可交互原型（5 页面 + Smart Animate）。方案设计逻辑清晰，体现了 AI 产品设计中的人机协作意识与系统边界把控能力。
